# Purpose, Scope And Users

1. The purpose of this document is to define the guidelines for the use of secure remote access and control software.
2. Remote access is a generic term used to describe the accessing of Agile Labs Pte Ltd &#39;s (Agile Labs&#39;s) computer network by individuals, who are located outside (for example from home or partner office) logging in and accessing application systems and data.
3. This document is applies to all Agile Labs Pte Ltd (Agile Labs) employees.
4. This document also applies to all employees from a vendor logging in to the system to solve a problem.
5. Users of this document are top management and persons responsible for suppliers, vendors, service providers and partners in Agile Labs.

# Roles and Responsibilities

1. Managers/TL shall determine and approve the request for remote access for an Agile Labs employee.
2. Managers/TL shall determine and approve the request for remote access on an ad hoc and as needed basis for a vendor or employee providing remote support for critical systems.
3. Managers shall verify the identity and suitability of the remote access user with TL before granting the request.
4. Manual will be provided to staff/vendor on how to install remote access software and usage.
5. All Agile Labs users shall only provide the credentials for remote access upon the permission granted by Managers only.
6. All Agile Labs users are required to ensure that remote access or control software will be inactive under normal circumstances.
7. All vendor granted remote access shall be advice to remove the remote control software [Team Viewer](https://www.teamviewer.com).
8. Managers/TL, or their assigned deputies, shall maintain a remote access log; which shall contain the date, time, user (requestor) name and activities performed for every remote access login by a vendor employee.
9. This log shall be available for audit purposes at any time.
